# camouflage.nvim

Hide sensitive values in configuration files during screen sharing. Masks secrets in `.env`, JSON, YAML, TOML, XML, `.http`, Terraform/HCL, Dockerfiles and more with extmarks, without changing the file, and covers picker previews, the quickfix list, diffs and terminal output. Includes a presentation mode and a screen shield.

No keymaps are set here: the ones suggested in the plugin's README use `<Leader>c`, which AstroNvim already uses. See the plugin's README for the commands and options.

**Repository:** <https://github.com/zeybek/camouflage.nvim>
