# camouflage.nvim

Hide sensitive values in configuration files during screen sharing. Masks secrets in `.env`, JSON, YAML, TOML, XML, `.http`, Terraform/HCL, Dockerfiles and more with extmarks, without changing the file, and covers picker previews, the quickfix list, diffs, and terminal output when enabled or in presentation mode. Includes a presentation mode and a screen shield.

No keymaps are configured; see the plugin's README for commands and suggested mappings.

**Repository:** <https://github.com/zeybek/camouflage.nvim>
