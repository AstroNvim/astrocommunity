# claudecode.nvim

Claude Code IDE integration for Neovim: a WebSocket MCP server that lets the Claude Code CLI see your buffers, selections, and diffs directly in the editor.

**Note**: requires the [Claude Code CLI](https://docs.anthropic.com/en/docs/claude-code) to be installed and on your `$PATH` separately; this plugin only provides the Neovim-side integration.

**Repository**: <https://github.com/coder/claudecode.nvim>
